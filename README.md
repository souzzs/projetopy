# projetopy
Calculadora de Média
App que calcula a média de duas notas e verifica a aprovação ou reprovação de um aluno

100% Python

Baixe o vscode e instale o interpretador python para o código poder ser executado ou use um interpretador online

pode ser usado para descobrir a média de duas notas e descobrir se o aluno passou de ano
